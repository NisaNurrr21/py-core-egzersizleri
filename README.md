# Python Core Egzersizleri

Bu depo, Python'un temel ve ileri seviye yapılarını kavramak için yazılmış 80 adet egzersiz ve testten oluşmaktadır.

* `01_string_isleme/`: Metin manipülasyonu (10 Görev)
* `02_koleksiyonlar/`: List, Dict, Set operasyonları (15 Görev)
* `03_generator_itertools/`: Bellek dostu iterasyonlar (10 Görev)
* `04_decorator_context/`: Meta programlama ve kaynak yönetimi (10 Görev)
* `05_oop/`: Nesne yönelimli programlama (15 Görev)
* `06_typing/`: İleri seviye tip belirteçleri (Protocol, TypedDict, Generic) (10 Görev)
* `07_asyncio/`: Asenkron programlama (10 Görev)

## Testleri Çalıştırma
Projeye entegre edilen Makefile sayesinde tüm 80 testi tek komutla çalıştırabilirsiniz:
```bash
make test
```
